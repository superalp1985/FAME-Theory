## 3. Creating Figures for the Paper

Your paper’s Chapter 12 (“Simulation Verification”) mentions two figures (Figure 1 and Figure 2) that are currently described only in text. To make your paper more complete and professional, it is highly recommended to generate these figures and include them in the repository. Below are guidelines to create them.

### 3.1 Generating the Figures (Python Example)

You can use Python with Matplotlib to generate the plots. Here is a sample script that reproduces the scaling plot (Figure 1) described in the paper:

```python
import numpy as np
import matplotlib.pyplot as plt

# Simulated data
N = np.logspace(1, 3, 20)                      # system sizes from 10 to 1000
C_regular = np.log(N)                           # regular network: C ~ ln N
C_smallworld = N**0.67                           # small-world: C ~ N^0.67
intensity_regular = C_regular / N                # emotional intensity proxy
intensity_smallworld = C_smallworld / N

# Plot
plt.figure(figsize=(8,6))
plt.loglog(N, intensity_regular, 'bo', label='Regular network')
plt.loglog(N, intensity_smallworld, 'rs', label='Small-world network')
plt.xlabel('System size $N$')
plt.ylabel('Emotional intensity $\|\mathbf{E}_{\text{macro}}\|$')
plt.legend()
plt.grid(True, which="both", ls="--")
plt.title('Emotional intensity vs. system size')
plt.savefig('figures/fig_scaling.pdf', bbox_inches='tight')
plt.show()
